# Visual Scene Plan

Use this as the first draft for the cinematic homepage journey and future 3D or design refinement.

| Scene | Visual | Message |
| --- | --- | --- |
| Opening | Dark roofline, slow rain, cinematic light | Southern Oregon storms are serious |
| Problem | Water overflows and scatters | Poor drainage damages homes |
| Craft | Aluminum profile forms in 3D | Continuous gutters are custom made |
| Solution | Water flows smoothly through gutter | Proper systems control runoff |
| Local trust | Calm home silhouette, warm light | Local owner, local service |
| CTA | Clear phone and quote form | Call Paul / request quote |

## Implementation Notes

- Keep the visuals abstract, premium, and lightweight.
- Preserve readable business copy in every scene.
- Treat WebGL as progressive enhancement with CSS fallbacks.
- Reduce particle counts and camera movement on mobile.
- Respect `prefers-reduced-motion` for scroll animation and 3D effects.
- Use final client photography or simple optimized placeholders when available.
