# Codex Rules

Paste these rules into every major Codex prompt for this project.

- Keep the build passing after every phase.
- Do not rewrite the whole project unless necessary.
- Do not remove working functionality.
- Do not add unnecessary dependencies.
- Do not use `npm audit fix --force`.
- Do not create a second lockfile.
- Do not hide business information behind animation.
- Maintain mobile performance.
- Add fallbacks for WebGL.
- Respect `prefers-reduced-motion`.
- Keep components small and understandable.
- Commit after each completed phase.
