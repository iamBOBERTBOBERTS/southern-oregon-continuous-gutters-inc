# Client QA Checklist

Use this before showing the site to the client.

## Desktop

- [ ] Homepage loads cleanly.
- [ ] Scroll scenes work smoothly.
- [ ] Text stays readable.
- [ ] Phone CTA works.
- [ ] Quote form works.
- [ ] No console errors.
- [ ] No broken images.

## Mobile

- [ ] No laggy 3D.
- [ ] Sticky call button works.
- [ ] Form is easy to use.
- [ ] Text is not too small.
- [ ] Sections do not overlap.
- [ ] Animations are simplified.

## Performance

- [ ] Build passes.
- [ ] No huge assets.
- [ ] WebGL lazy loads.
- [ ] Images optimized.
- [ ] Reduced motion works.
- [ ] Lighthouse checked.

## Business

- [ ] Name is correct.
- [ ] Phone number is correct.
- [ ] Services are accurate.
- [ ] No fake claims.
- [ ] CTA is obvious.
