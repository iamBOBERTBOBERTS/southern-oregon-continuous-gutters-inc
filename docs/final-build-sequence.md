# Final Build Sequence

Use this exact order for the project buildout and launch workflow.

1. Create project.
2. Build static homepage.
3. Add conversion copy.
4. Add responsive layout.
5. Add quote form.
6. Add SEO.
7. Add basic motion.
8. Add WebGL hero.
9. Add scroll-driven scenes.
10. Optimize mobile.
11. Add real photos/assets.
12. Test form and phone links.
13. Deploy preview.
14. Review with client.
15. Polish based on feedback.
16. Connect final domain.
17. Launch.

## Operating Notes

- Keep the site buildable after each phase.
- Keep phone and quote CTAs visible before adding advanced effects.
- Do not add the advanced scene system until the preview is stable.
- Validate with `npm run lint`, `npm run typecheck`, and `npm run build` before preview or client review.
